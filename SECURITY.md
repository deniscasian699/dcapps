## Reporting a Vulnerability

Report security vulnerabilities **responsibly and privately**.

> ⚠️ **Do not open a public GitHub issue for security vulnerabilities.**

### How to Report

1. Email **[support@rdcapps.com](mailto:support@rdcapps.com)**
   with the subject `[SECURITY] DC Tools Vulnerability Report`.
2. Include a description, reproduction steps, potential impact, Android and
   app versions, and a suggested fix if available.
3. Do not include private files, purchase tokens or other sensitive information
   in public reports.

Reports are assessed according to severity. A response or fix deadline is not guaranteed.

## Scope

| In Scope ✅ | Out of Scope ❌ |
|---|---|
| DC Tools Android app | Google AdMob infrastructure |
| App purchase and entitlement integration | Google Play / RevenueCat infrastructure |
| Tool interface and file handling | Physical device attacks |
| App settings and local storage | Third-party sites |

---

## Known Security Practices

- Many tools process files locally on the device.
- Advertising and purchase services use encrypted network connections.
- Google Play processes payment details.
- RevenueCat manages purchase validation and entitlements.
- Advertising SDK data handling is disclosed in the [Privacy Policy](./PRIVACY_POLICY.md).
